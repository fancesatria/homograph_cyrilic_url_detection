# Homograph & Cyrillic URL Detection

A machine learning pipeline for detecting homograph phishing attacks, where Latin characters in a domain are swapped for visually identical Cyrillic characters (like `a` → `а` or `o` → `о`) to fool users into visiting a fake site that looks legitimate.

URLs are classified into three categories: legitimate (from the Tranco top sites list), phishing (from PhishTank), and homograph — synthetic samples created by injecting Cyrillic look-alikes into otherwise legitimate domains.

## How it works

The pipeline starts by pulling domains from Tranco and phishing URLs from PhishTank, cleaning them up, and balancing both sets to 25,000 samples each. From the legitimate set, a synthetic homograph class is generated by swapping 1-2 vulnerable characters (a, e, o, i, c, p, x, l) per domain with their Cyrillic equivalents.

From there it extracts a set of features per URL — length, digit count, special character count, Shannon entropy, whether it's punycode-encoded, script mixing between Latin and non-Latin characters, dot count, and TLD length — and checks for multicollinearity before dropping redundant ones.

Three feature sets are compared: basic statistical features on their own, basic features combined with a SHA-256 byte representation of the URL, and the full engineered feature set. Four models (Logistic Regression, Random Forest, XGBoost, CatBoost) are trained and tuned on each, using RandomizedSearchCV with 5-fold CV. Results are compared across accuracy, precision, recall, and F1, with confusion matrices and feature importance plots for the best-performing models.

## Features used

- `length` — length of the URL string
- `num_digits` — number of digits
- `num_special` — number of special/punctuation characters
- `entropy` — Shannon entropy of the string
- `is_punycode` — whether the URL contains `xn--`
- `script_mixing` — whether Latin and non-Latin characters appear together
- `num_dots` — number of dots
- `tld_length` — length of the TLD

## Running it

This was built as a Colab notebook, so it relies on `gdown` to pull the dataset from Google Drive and `google.colab.sheets` to export results at the end. Running it outside Colab means swapping that last part for something like `result_df.to_csv("results.csv")`.

Install dependencies:

```bash
pip install gdown pandas numpy matplotlib seaborn scikit-learn xgboost catboost
```

Then run:

```bash
python homograph_cyrillic_url_detection.py
```

## Dataset sources

- Tranco List — [tranco-list.eu](https://tranco-list.eu/)
- PhishTank — [phishtank.org](https://phishtank.org/)

The homograph class isn't from an external source — it's generated synthetically from the Tranco sample using the character mapping described above.
